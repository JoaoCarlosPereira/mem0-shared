# Product

## Register

product

## Users
AI engineering teams, developers, and autonomous agents operating on a local LAN. They use this interface to inspect, manage, and debug shared project context and memories.

## Product Purpose
A local-first, team-shared memory layer for AI engineering agents. It provides a central, durable hub (OpenMemory) for agents to store and retrieve context without sending data to the cloud. Success looks like seamless observability and instant memory management.

## Brand Personality
Modern, clean, and technical. It should feel like a precision instrument (e.g., Vercel, Linear).

## Anti-references
- No bloated enterprise UI patterns.
- No bright, playful, or "bubbly" colors.
- Avoid the saturated AI-app "cream/sand" default; keep it crisp.

## Design Principles
- **Developer-First Clarity**: Surface the data (memories, specs, logs) without distraction. High information density wins over decorative white space.
- **Local & Fast**: The interface must feel instant, reflecting its local-LAN architecture. Minimize transitions that slow down workflows.
- **Precision over Playfulness**: Maintain a restrained, utilitarian aesthetic. 

## Accessibility & Inclusion
Standard WCAG AA compliance. Respect `prefers-reduced-motion` for all transitions.
